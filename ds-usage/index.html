🧾用量明细怎么看

重要：DeepSeek 官方 API 不提供公开的 Token 用量明细接口——API Key 只能查到 /user/balance 余额（本次已实测）。逐笔/按日/按模型的消费明细，需登录开放平台后台查看。
1. 登录 platform.deepseek.com → 左侧菜单「用量 / Usage」；
2. 可查看账户总余额、赠送/充值余额，支持按 API Key / 模型 / 时间区间 筛选每次请求的 Token 消耗明细；
3. 用量数据存在约 5 分钟延迟，非实时；
4. 想在本工具持续统计，请将同一 Key 用于日常调用，本页「本机计量器」会累加记录。
